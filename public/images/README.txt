The homepage portrait comes from the owner-supplied GitHub account:
https://github.com/ImaneBenzegunine.png?size=800
It is stored locally as imane-profile.jpg without image alteration.
To replace it, place the preferred JPG, PNG, or WebP file here, then set profile.portrait.src
in src/content.ts to /images/your-filename.webp (or the chosen extension).
Adjust profile.portrait.position to control the crop. Rebuild Docker afterward.
Unavailable images fall back to a labeled monogram.
